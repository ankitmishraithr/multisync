          How syncing works
          1. Each video has a start time. All videos begin at their own start time together.
          2. A start time can be typed as 90, 1:30 or 1m30s. For a live stream it means seconds behind live.
          3. While watching, shift any video in 0.1 second steps until they line up. The link updates as you go.
          4. The page checks every half second and pulls back any video that drifts.
          5. Everything is saved only in this browser. Nothing is uploaded.
